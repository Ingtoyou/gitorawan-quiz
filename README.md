# เว็บเพจแนะนำตัว
ใบงานปฏิบัติการ Git พื้นฐาน รายวิชา เทคโนโลยีสารสนเทศ

## ผู้จัดทำ
- นางสาวอรวรรณ สีวิจี๋ รหัสนักศึกษา 66242206041-5

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|------|---------|
| index.html | หน้าหลัก แสดงส่วนหัวและปุ่มสลับธีม |
| about.html | หน้าประวัติส่วนตัว |
| css/style.css | รูปแบบการแสดงผล |
| js/script.js | สคริปต์สลับธีม มืดสว่าง |

## วิธีเปิดใช้งาน
เปิดไฟล์ index.html ด้วยเว็บเบราว์เซอร์

## รายการ branch
| branch | หน้าที่ |
|--------|---------|
| main | สายหลัก |
| feature/header | ส่วนหัวของหน้าเว็บ |
| feature/about | หน้าประวัติส่วนตัว |
| feature/style | ไฟล์ CSS และ .gitignore |
| feature/script | สคริปต์สลับธีม |
| docs/readme | เอกสารประกอบ |
| experiment/merge-conflict | ทดลองแก้ conflict |
